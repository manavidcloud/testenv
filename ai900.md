## 🌍 Fundamental Concepts

### What is Artificial Intelligence?

**Artificial Intelligence (AI)** is software that imitates human capabilities, such as:

* Predicting outcomes and recognizing patterns based on historical data
* Recognizing abnormal events and making decisions
* Interpreting visual input
* Understanding language and engaging in conversations
* Extracting information from sources to gain knowledge

**In short:** predicting, recognizing, interpreting, understanding language, and extracting information.

## 🤖 Fundamentals of Machine Learning

**Machine Learning (ML)** is the process of creating **predictive models** by finding **relationships and patterns** in data.

### 🔍 Key Concepts

* Machine learning uses **training data**, which is typically based on **past observations**.
* This data can be **structured** or **semi-structured**.
* Most training data includes **labels** (e.g., “spam” or “not spam”).
* The labeled data is **ingested** into the ML system.
* An **algorithm** analyzes the data to **generalize relationships** between input features and target labels.
* It helps to **classify**, **categorize**, or **predict** outcomes.
* Once trained, the algorithm produces a **model** — a mathematical representation of learned patterns.
* The **model** is then used to process **inference data** (unlabeled data) to generate **predictions** or **inferred labels**.

---

### ⚙️ Machine Learning Workflow

```
Training Data  →  Algorithm  →  Model  →  Prediction (Inferred Label)
                                      ↑
                             Inference Data (Unlabeled Features)
```

---

### 🧩 Key Components

1. **Training Data**

   * Based on **historical or past observations**.
   * Contains **input features (X)** and **known labels (Y)**.
   * Used to **train** the algorithm.

2. **Algorithm**

   * Learns and **generalizes** the relationship between **features (X)** and **labels (Y)**.
   * Produces a **model** capable of making predictions.

3. **Model**

   * The **output** of the training process.
   * Accepts **inference (unlabeled)** data as input.
   * Generates **predicted labels or outcomes** based on learned patterns.

---

### 💡 Example: Spam Email Detection

1. **Training Data:**

   * A dataset of emails labeled as **“spam”** or **“not spam.”**

2. **Algorithm:**

   * Learns which words, phrases, or sender patterns are associated with spam emails.
   * Builds a model that understands these relationships.

3. **Model:**

   * Once trained, the model can analyze **new, unseen emails** (inference data).
   * Predicts whether each new email is **spam** or **not spam** based on learned patterns.
